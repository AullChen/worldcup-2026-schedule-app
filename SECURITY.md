# Security Policy

## Supported Versions

The `main` branch is the supported version.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory when the repository is hosted on GitHub, or by contacting the repository owner directly.

Do not disclose vulnerabilities publicly until a fix or mitigation is available.

## Scope

This project is a static app plus an optional Worker-style sync endpoint. Avoid adding secrets to the repository. If a future deployment uses API keys for sports data providers, store them in the hosting platform secret manager rather than in source files.
